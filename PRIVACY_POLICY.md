# Privacy Policy — Fagor 8050 M CNC Advisory API

Effective date: 2026-08-19

This API receives CNC program text and machining parameters solely to return
static advisory checks and calculations. Do not submit personal information,
trade secrets, export-controlled data, or production files you are not
authorized to process.

The reference implementation does not include a database and does not
intentionally retain request bodies. The hosting provider may temporarily
process and log technical request metadata for security, diagnostics, and
service operation. Before public use, the service owner must replace this draft
with accurate contact, hosting, retention, deletion, jurisdiction, and policy
change information for the deployed service.

This service does not control machinery and does not guarantee that generated
or reviewed CNC programs are safe or correct.
